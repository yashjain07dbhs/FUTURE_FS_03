# Flavor Cottage - Restaurant Website

## About the Project

This project is a professional and responsive restaurant website
created as part of the Future Interns Full Stack Web Development
Internship - Task 3.

The website is designed for Flavor Cottage, a multi-cuisine
restaurant located in Bhendi Bazar, Mumbai.

## Features

- Responsive restaurant homepage
- Navigation bar
- Restaurant introduction
- Menu section
- Popular food categories
- Why visit us section
- Food and restaurant gallery
- Contact information
- Reservation request form
- Call restaurant button
- WhatsApp button
- Mobile responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## Purpose

The purpose of this website is to provide a modern online
presence for a local restaurant.

The website makes it easier for customers to:

- Discover the restaurant
- Explore food options
- Find contact information
- Contact the restaurant
- Send a reservation request
- Access the restaurant through WhatsApp
